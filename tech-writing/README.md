# Tech Writing

Technical writing support for Claude Code — transform documents between internal and client-facing audiences.

## Skills

- **client-facing-doc** — Convert internal or reserved technical documentation into a polished,
  client-facing deliverable. Silently removes confidential content (costs, rates, effort estimates,
  internal planning, AI artifacts, drafts, internal notes) while preserving and improving the
  customer-relevant technical substance. Produces the deliverable in the project's output folder and a separate
  internal redaction audit for verification. Bilingual (English/Italian).

- **bid-delivery-summary** — The internal counterpart of `client-facing-doc`. Distills a project
  assessment, estimation, or solution design into a concise internal commercial & delivery summary
  for sales, bid, and delivery stakeholders: scope, resources, effort, risks, dependencies, a
  bid-readiness verdict, and a delivery-readiness assessment. Effort-only by default; costs appear
  only when an approved cost model is present and explicitly authorized. Output opens with a mandatory
  `INTERNAL USE ONLY` notice. Bilingual (English/Italian).

## Status

This plugin is in early development. More skills will be added in future releases.
