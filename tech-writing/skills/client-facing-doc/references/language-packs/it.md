# Language Pack: Italiano (it)

Usare queste convenzioni quando il documento è prodotto in italiano. La skill preserva la struttura
del documento di origine, quindi questo pacchetto fornisce etichette e convenzioni di stile comuni,
non un modello fisso.

## Convenzioni

- Formato data: `GG/MM/AAAA` oppure `D mese AAAA`.
- Usare frasi complete e ben sviluppate; preferire "la soluzione fornisce…" a note telegrafiche.
- Acronimi universalmente riconosciuti che possono restare non espansi: API, HTTP(S), REST, SQL,
  JSON, XML, URL, CPU, RAM, SLA, UI, UX. Espandere tutti gli altri alla prima occorrenza.
- Evitare la prima persona plurale che implica l'organizzazione fornitrice ("realizzeremo") dove una
  costruzione neutra è preferibile ("la soluzione realizza", "l'implementazione fornisce").

## Formule ricorrenti

- Apertura di sezione: "Questa sezione descrive…"
- Connettore di motivazione: "Questa scelta è motivata da…"
- Dipendenze: "La soluzione dipende da…"
- Rischi: "Esiste il rischio che…, mitigato da…"
