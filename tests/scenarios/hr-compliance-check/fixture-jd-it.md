# Cercasi Sviluppatore Backend — Team Piattaforma

## Chi siamo

Example Srl sviluppa software gestionale per aziende di logistica. Il team Piattaforma
lavora da remoto, con un incontro in sede al trimestre.

## Il ruolo

Il candidato ideale progetterà e manterrà i servizi backend della piattaforma.

**Sede:** full remote (Italia) | **Riporta a:** Engineering Manager | **Contratto:** tempo indeterminato

## Responsabilità

- Progettare e sviluppare API REST in Go
- Mantenere la pipeline di rilascio continuo
- Partecipare alle code review del team

## Requisiti

- Esperienza con Go e PostgreSQL
- Madrelingua italiana
- Bella presenza
- Automunito
- Residente in zona

## Cosa offriamo

- Buoni pasto, formazione, orario flessibile

## Pari opportunità

Example Srl è un datore di lavoro che garantisce pari opportunità. Saranno garantiti
accomodamenti ragionevoli per le persone candidate con disabilità.
