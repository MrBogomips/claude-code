# Recap

## Format

Write the recap in the language of the conversation. Structure:

```
Voice maintenance — 7 proposals
Global store: <path> · Project store: .personal-voice/ (personal)

1. PROMOTE → global › languages/it.md › Avoid
   [it] Avoid "pertanto"; drop it or restructure the sentence. (evidence: 2)
   Evidence: 2026-09-18 meeting follow-up to the team · "Pertanto, rinviamo…" → "Rinviamo…"
             2026-09-25 retrospective reminder to the team · "non uso mai 'pertanto'"

2. CONFLICT → global › languages/it.md › Audiences
   A (rule):        [it] [to clients] Use "Lei"; close with "Buona giornata". (evidence: 2)
   B (observation): [it] [to clients] Use "tu". (evidence: 2)
   Choose: keep A · keep B · qualify (e.g. B only [to long-standing clients])

3. REVIEW (stale) → global › core.md › Tone
   Alternate a long sentence with two short ones… (last reinforced 2026-02-10)
   Keep (not asked again for six months), or remove?

…

At the end of the run the date is recorded in the global store.

Reply with the items to apply, e.g. "1, 3 remove, 2 keep A", or "all" for
every item that needs no decision.
For a promotion you can also write "1 edit: <new text>" or "1 scope: project",
"1 scope: [to colleagues]". Items you do not name stay as they are.
```

For each item: a number, the action, the destination (store › file ›
heading), the before and after text, and the evidence (source date, text
label and excerpt). Link items that depend on each other ("needed if 4 is
applied").

If there is nothing to propose, say so in one line and record the run date.

End the turn after the recap.

## Reading the reply

- Map every item number named to a decision: apply, keep, remove, keep A or
  B, qualify, edit with the given text, or change scope.
- A number without a decision on an item that needs one (a CONFLICT, a
  REVIEW) → ask for that decision.
- "all" applies every item that needs no decision; ask for the others.
- A vague reply ("ok", "sounds good", "yes") → ask for the item numbers.
- A request to promote a single-evidence observation, or any other change the
  author names, is allowed: add it as an item and confirm it.
- Echo the final list ("Applying 1, 3 (remove), 2 (keep A).") before writing.
